## Data Format

Each log entry follows the format:

```text
[YYYY-MM-DD HH:MM:SS] Temperature: XX.X°F (XX.X°C), Status: NORMAL/FEVER/HYPOTHERMIA
```

## Temperature Ranges

- **Normal**: 97.0°F - 99.5°F (36.1°C - 37.5°C)
- **Fever**: > 100.4°F (> 38.0°C)
- **Hypothermia**: < 95.0°F (< 35.0°C)
